# deedroll

This package is a pointer to [`@antharmaya/deedroll`](https://www.npmjs.com/package/@antharmaya/deedroll).
It exists so that the short name works:

```
npx deedroll npm:@modelcontextprotocol/server-filesystem
```

deedroll checks an MCP server before you install it: what its code reads, runs and
contacts, against what its registry listing says. It never executes the server.

Documentation, source and issues: <https://github.com/antharmaya/deedroll>
