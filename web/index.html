              How this was measured

              The registry, day by day

              Every day, mcpscan records what each listing in the official MCP registry declares, and what a slice of hosted servers' tools say. Each day is chained to the one before by its hash, so the record cannot be quietly rewritten, and you can check that yourself.

              Loading the record…

              How a scan works

              1. Fetch it

                Packages come straight from npm or PyPI and are checked against the registry's own hash. A hosted server is asked for its list of tools, and for how its sign-in works.

              2. Read it without running it

                Packages are unpacked in memory: install scripts never run and nothing touches your disk. Hosted servers get discovery requests only, never a tool call.

              3. Compare the label with the code

                What its registry listing declares, against what the code reads, runs and contacts. Every finding points at a file and a line.

              Every check mcpscan makes

              What a result is, and isn't: mcpscan reads a server's label beside its code, without running either. A difference between them is a question for the publisher, not a verdict on the server, and most turn out to be documentation gaps. It does not prove a server safe, and it does not yet trace whether a tool's input can reach a shell or a file path, which is where most of 2026's MCP vulnerabilities were found.

              What leaves your browser: package names and versions (to npm or PyPI, the MCP registry and OSV.dev), and for a hosted server, the discovery requests to that server. If you choose the relay, the URL goes to mcpscan's relay, which keeps nothing. Tools you scan are remembered in this browser only, so a later change stands out.

              Check what your agents already trust

              The command line also probes hosted servers and pins their tools, reads the MCP configs of Claude Code, Codex, Cursor, Devin and Gemini CLI without launching anything, and writes SARIF for code scanning.
